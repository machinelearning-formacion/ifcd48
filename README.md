# IFCD48 · Programación de Redes Neuronales - Machine Learning · Recursos del libro

Material complementario del libro para la especialidad formativa IFCD48. Cada código QR del
libro lleva a uno de estos recursos:

- **Ejecuta**: cuadernos que se abren en el navegador (JupyterLite) o, los que usan
  TensorFlow, en Google Colab.
- **Explora**: herramientas interactivas.
- **Compruébalo**: tests de autoevaluación.

La tabla `recursos.csv` es la fuente única: `herramientas/construir.py` genera la web y el
bloque de recursos del libro.

Web publicada: <https://especialidades-formativas.github.io/ifcd48/>
